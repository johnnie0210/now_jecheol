# 지금제철 (now_jecheol)

오늘이 속한 달에 제철인 **과일·채소·수산물**을 알려주는 설치형 웹앱(PWA)입니다.
장보기 전에 "지금 뭐가 제철이지?"를 확인하는 용도로, 회원가입 없이 설치 후 바로 쓰고 오프라인에서도 동작합니다.

## 화면

| 화면 | 내용 |
|---|---|
| 이번 달 (홈) | 기기 날짜의 달을 자동 선택해 "11월의 제철 식재료" 목록. 분류 탭(전체/과일/채소/수산물) |
| 월별 | 1~12월 가로 스크롤 버튼(달마다 품목 수 표시). 고른 달의 제철 목록 + 분류 탭 |
| 검색 | 전체 79종에서 품목명 검색(공백·대소문자 무시). 분류 탭과 함께 적용. 결과가 없으면 "검색 결과가 없어요" |
| 즐겨찾기 | 저장한 품목 목록 |
| 요리 레시피 | 상세의 어울리는 요리를 누르면 열림. 요리 이름·인분·소요 시간·재료(체크박스)·만드는 순서(번호) |
| 상세 | 상단 큰 이미지·품목명·분류·제철 기간·특징 전문·12개월 제철 표시(이번 달 테두리)·즐겨찾기 토글 |

- 카드 : 왼쪽 이미지 썸네일, 품목명, 분류 뱃지(과일 주황 / 채소 초록 / 수산물 파랑), 제철 기간, 특징 한 줄
- 화면 이동은 주소 해시(`#home`, `#month-11`, `#search`, `#fav`, `#item-12`, `#recipe-12-0`)라 휴대폰 뒤로가기 버튼이 동작합니다.

## 데이터

- `assets/jecheol.json` — 앱이 쓰는 유일한 데이터 (79종 : 과일 22 · 채소 29 · 수산물 28, 레시피 232개, v4)
  - 출처 : jecheori.com 월별 제철 달력 (2026-11-24 수집)
- **제철 여부는 `months` 배열로만 판정**합니다 (`app.js`의 `isInSeason`). `season` 문자열은 화면 표시용입니다.
  (11~5월처럼 해를 넘기거나, 감자처럼 구간이 여러 개인 경우 문자열 계산이 틀리기 때문)
- 데이터 품목·제철 기간·특징을 바꿀 때는 JSON만 고치고, `sw.js`의 `CACHE` 버전을 올려 주세요.
- JSON을 읽지 못하거나 형식이 틀리면 화면에 오류 문구를 보여 줍니다.

## 상세 : 고르는 법 · 보관법 · 어울리는 요리 (v2 데이터)

- JSON v2의 `pick`(고르는 법) · `store`(보관법)를 그대로, `dishes`(어울리는 요리)는 이름 칩으로 표시합니다. 칩은 누를 수 없습니다.

## 요리 레시피 (v4 데이터)

- JSON의 `recipes`(요리 이름 → 레시피)를 그대로 씁니다. 앱에 들어 있는 데이터만 쓰고 외부에서 받지 않으므로 오프라인에서도 보입니다.
- 상세의 어울리는 요리 중 `recipes`에 있는 요리만 초록 칩(›)으로 눌러서 레시피 화면으로 갑니다. 레시피가 없는 요리("그대로 먹기" 등)는 누를 수 없는 회색 글자입니다.
- 레시피 주소는 `#recipe-<품목 id>-<어울리는 요리 순번>`입니다. 레시피가 없는 주소로 열면 그 품목 상세로, 품목도 없으면 홈으로 갑니다.
- 소요 시간(`time`)은 "약 3일"·"약 1주일"처럼 데이터 그대로 표시합니다(분으로 바꾸지 않음).
- 재료 체크 표시는 장보기·요리 중 확인용이며, 화면을 다시 열면 지워집니다(저장하지 않음).

## 품목 이미지 (v3 데이터)

- 이미지 파일 : `assets/images/<JSON image 필드>` (79장, WebP 1600px, 받은 파일 그대로). 파일명은 JSON의 `image` 필드와 정확히 같아야 합니다.
- 목록 썸네일 : `assets/images/thumb/<같은 파일명>` (256px로 줄인 사본, 합계 약 230KB). 원본 79장을 목록에서 디코딩하면 휴대폰에서 스크롤이 끊길 수 있어 따로 둡니다.
  - 이미지를 바꾸거나 추가하면 `node build/make-thumbs.mjs`로 다시 만들고, `sw.js`의 `CACHE` 버전을 올려 주세요. (설치할 패키지 없음. PC의 Edge/Chrome을 헤드리스로 써서 줄임)
- 표시 : 홈·월별·검색·즐겨찾기 카드는 왼쪽 썸네일, 상세는 상단에 원본을 크게 표시합니다.
- 실패 처리 : 썸네일이 없으면 원본으로 한 번 더 시도하고, 그래도 없으면(또는 `image` 필드가 없으면) 이미지 자리에 기본 아이콘(🌱)을 보여 줍니다. 나머지 내용은 그대로 보입니다.
- 오프라인 : 썸네일은 서비스 워커 설치 때, 상세용 원본은 앱을 연 뒤 뒤에서 기기에 저장합니다(약 7MB). 이미지는 모두 앱에 들어 있는 파일이며 외부에서 받지 않습니다.

## KAMIS 시세 ("지금 사면 싸요")

- API : KAMIS Open API `dailyPriceByCategoryList` (일별 부류별 도·소매가격), `p_product_cls_code=01`(소매), `p_country_code` 빈 값(전국), `p_regday`=기기 날짜의 **전날**
- 부류 : 100 식량작물(감자·고구마) · 200 채소류 · 400 과일류 · 600 수산물 → **부류마다 하루 1번(하루 4번)**
- 캐시 : 결과를 날짜·부류별로 기기에 저장(`now_jecheol.kamis.<날짜>.<부류>`), 같은 날에는 다시 부르지 않음. 3일 지난 캐시는 지움
  - 네트워크 실패는 저장하지 않아 다음 실행 때 다시 시도합니다. API 응답 오류(인증 실패 등)는 그날 저장해 반복 호출을 막습니다.
- 판정 : 소매 당일가 vs 평년가 (`dpr1` vs `dpr7`)
  - 당일가 < 평년가 × 0.9 → **지금 사면 싸요** / 평년가 × 0.9 ≤ 당일가 < 평년가 → 평년보다 조금 싸요 / 당일가 > 평년가 × 1.1 → 평년보다 비싸요 / 그 외 뱃지 없음
  - 당일가나 평년가가 없으면(`-`) 판정하지 않음. 당일가가 없으면 시세 카드도 숨김
- 화면 : 홈 상단 "지금 사면 싸요"(이번 달 제철 + 지금 사면 싸요 판정만, 없으면 숨김), 카드의 판정 뱃지, 상세 시세 카드(소매가 · 단위 · 평년 대비 % · 기준일 · 품종/등급, "소매가 기준 · 출처: KAMIS")
- 인증키가 없거나, 오프라인·호출 실패·가격 없음이면 시세 영역만 숨기고 제철 정보는 그대로 보여 줍니다.

### 품목 매핑 (`kamis.js`의 `MAP`)

KAMIS 코드표(`productInfo`)의 품목명·품종명으로 확인한 44종만 매핑했습니다. 수입·염장·굴비·세척수입처럼 다른 상품인 품종은 넣지 않았습니다.
매핑하지 않은 35종 : 레드향 살구 천도복숭아 자두 밤 대추 대봉감 키위(참다래) 황금향 / 냉이 풋마늘 곰취 두릅 아스파라거스 완두콩 풋콩 늙은호박 토란 표고버섯 / 대게 방어 아귀 청어 도다리 꼴뚜기 미더덕 숭어 키조개 병어 농어 낙지 대하 흰다리새우 꽁치 도루묵

### 인증키 넣기 (소스·깃에 넣지 않음)

키는 `config.local.js`(깃 제외)에 들어가며, 환경변수로 만듭니다.

```powershell
cd D:\app\now_jecheol
$env:KAMIS_CERT_KEY='발급받은 키'; $env:KAMIS_CERT_ID='요청자 ID'; node build/make-config.mjs
# 개발·테스트용 공개 키 : $env:KAMIS_CERT_KEY='TEST'; $env:KAMIS_CERT_ID='TEST'; node build/make-config.mjs
# 키 지우기(시세 끔)      : node build/make-config.mjs --clear
```

- 배포할 때는 배포 단계에서 같은 스크립트로 `config.local.js`를 만들어 함께 올립니다(예: GitHub Actions secret → 환경변수).
- 주의 : 브라우저에서 바로 KAMIS를 부르는 구조라, 배포된 앱에 들어간 키는 사용자가 브라우저 개발자 도구로 볼 수 있습니다.

## 즐겨찾기 저장

- 브라우저 저장소(localStorage, 키 `now_jecheol.favorites`)에 품목 id 배열로 저장합니다.
- 그 기기에만 저장되고, 앱을 껐다 켜도 유지됩니다. (앱 삭제·브라우저 데이터 삭제 시 지워짐)

## 파일 구성

```
now_jecheol/
├─ index.html              화면
├─ styles.css              스타일 (흰 배경, 카드형, 시스템 글꼴)
├─ app.js                  앱 로직 (데이터 로딩·필터·화면 이동·즐겨찾기)
├─ kamis.js                KAMIS 시세 (품목 매핑·호출·캐시·판정)
├─ config.local.js         KAMIS 인증키 (깃 제외, build/make-config.mjs 로 생성)
├─ assets/jecheol.json     제철 데이터 (v3)
├─ assets/images/          품목 이미지 79장 (+ thumb/ 목록용 축소본)
├─ manifest.webmanifest    PWA 설정
├─ sw.js                   서비스 워커 (오프라인)
├─ icons/                  앱 아이콘 (192, 512, 마스커블 512)
├─ build/make-icons.mjs    아이콘 생성 스크립트 (node build/make-icons.mjs)
├─ build/make-config.mjs   인증키 설정 파일 생성 (환경변수 → config.local.js)
└─ build/make-thumbs.mjs   목록용 썸네일 생성 (node build/make-thumbs.mjs)
```

프레임워크나 빌드 과정 없이 HTML·CSS·JavaScript만 씁니다. 외부 요청은 KAMIS 시세 조회뿐입니다(인증키가 있을 때만).

## 로컬에서 미리보기

```powershell
cd D:\app\now_jecheol
npx serve .
```

표시된 주소(예: http://localhost:3000)를 엽니다. 데이터 파일을 불러오므로 `index.html`을 더블클릭해 열면 동작하지 않습니다. 반드시 서버로 여세요.

## 배포 (GitHub Pages)

1. GitHub에 `now_jecheol` 저장소를 만들고 이 폴더를 push
2. Settings → Pages → Deploy from a branch → `main` / `(root)`
3. `https://<계정>.github.io/now_jecheol/` 에서 열고 홈 화면에 추가
